# Vaultify

Vaultify is a digital product vault that stores purchase records, warranties, manuals, and ownership history.

## Project structure

- `backend/` — Node.js + Express API server
- `mobile/` — Expo React Native app

## Phase 1 Setup

1. Backend API scaffold
2. Expo mobile scaffold
3. MongoDB connection configured for development
4. Basic navigation and dashboard UI

## Getting started

### Backend

```bash
cd backend
npm install
npm run dev
```

### Mobile

```bash
cd mobile
npm install
npx expo start
```
